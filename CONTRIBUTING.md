# Contributing to Slipway

Thank you for your interest in contributing to **Slipway**! As an open-source project management and engineering planning platform, we welcome contributions from developers, designers, and architects worldwide.

---

## 🛠️ Development Setup

1. **Fork and Clone:**
   ```bash
   git clone https://github.com/imuzax/Slipway.git
   cd Slipway
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Start Development Server:**
   ```bash
   npm run dev
   ```

4. **Verify TypeScript & Builds:**
   ```bash
   npm run typecheck
   npm run build
   ```

---

## 📋 Pull Request Guidelines

1. Create a descriptive feature branch (`git checkout -b feat/your-feature-name`).
2. Follow Conventional Commits format (`feat: ...`, `fix: ...`, `docs: ...`, `refactor: ...`).
3. Ensure no TypeScript compiler errors exist (`npm run typecheck`).
4. Submit your Pull Request targeting the `main` branch with detailed release notes.
