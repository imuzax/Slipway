# Security Policy

## Supported Versions
We actively provide security updates for the current major version.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within Slipway, please disclose it responsibly by sending an email to `security@slipway.dev` or creating a private security advisory on GitHub. Please do not open public issues for sensitive security vulnerabilities.
