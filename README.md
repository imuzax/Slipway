## What is DevForge?

DevForge turns a five-minute project brief into a complete, actionable engineering roadmap:

1. **Describe** — a guided 5-step wizard: brief, tech stack, features, team & timeline.
2. **Forge** — the AI engine returns **6 phases** (Requirements → Design → Setup → Development → QA → Launch) with ~40 prioritized tasks, durations, deliverables, pro tips, tooling, key milestones, a risk register and tech recommendations.
3. **Track** — flip task and phase statuses; progress rolls up automatically to the project level.
4. **Report** — one click downloads a branded multi-page **PDF** (cover + progress donut, task tables, milestones, risk assessment).

### AI engine — two modes

| Mode | How |
|---|---|
| **Offline forge engine** (default) | A deterministic planning engine bundled in the app. Always works, zero config, fully private. |
| **Groq · `llama-3.1-70b-versatile`** | Paste a free Groq API key (avatar menu → *AI engine settings*). Roadmaps are then generated by the Llama model via the OpenAI-compatible Groq API, with JSON-mode + validation + automatic fallback to the offline engine on failure. The key never leaves your browser. |

### Persistence

DevForge is **local-first**: users, sessions, projects and roadmaps persist in `localStorage`, so the full product flow (register → plan → track → export) works end-to-end with no server. The data layer (`src/lib/store.ts` + `src/state/AppContext.tsx`) is isolated behind a small API, designed to be swapped for a REST/MongoDB backend without touching the UI.

## Features

- **Landing page** with a live “forge terminal” that simulates a roadmap being generated
- **Auth** — register / login / demo workspace, role selection (developer · manager · freelancer)
- **Dashboard** — animated stat cards, search + status/category filters, project cards with live progress, empty states
- **5-step project wizard** — validation, tag pickers for the stack, dynamic feature list, review screen
- **Roadmap page** — timeline of expandable phase cards, task status cycling (todo → in progress → done), phase status menu, per-phase progress, milestones, risks & mitigations, tech recommendations, regenerate (versioned), AI-generation overlay with staged progress
- **Report page** — on-screen paper preview + one-click PDF download (jsPDF + autotable, fully client-side)
- **Project settings** — edit everything, danger-zone delete with confirmation
- Toasts, skeleton-free reveals, keyboard-friendly modals, fully responsive (mobile → desktop)

## Run it locally

```bash
# 1. clone & install
git clone https://github.com/<your-username>/devforge.git
cd devforge
npm install

# 2. start the dev server
npm run dev            # → http://localhost:5173

# 3. production build
npm run build          # → dist/ (purely static, host anywhere)
npm run typecheck      # optional: strict TS check
```

**No environment variables are required.** To use the real Groq model instead of the offline engine: get a free key at [console.groq.com](https://console.groq.com), then open the avatar menu → *AI engine settings* and paste it.

### Deploy (static)

The build is a static bundle — deploy `dist/` to Vercel, Netlify, Cloudflare Pages or GitHub Pages as-is.

## Publishing this repo to GitHub

```bash
# from the project root
git init
git add .
git commit -m "DevForge — AI project planner & roadmap generator"
git branch -M main

# option A: with the GitHub CLI (creates the public repo for you)
gh repo create devforge --public --source=. --remote=origin --push

# option B: create the repo on github.com first (no README), then:
git remote add origin https://github.com/<your-username>/devforge.git
git push -u origin main
```
